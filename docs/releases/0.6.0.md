# WebDesk 0.6.0

发布日期：2026-10-25。

## 升级

网页、Windows 客户端和信令服务须同步更新。退出旧客户端后安装 `WebDesk-0.6.0-win-x64.exe`，Mac Chrome 用 `⌘⇧R` 强制刷新网页，再重新连接。

本版要求会话协议版本 1。旧版注册和连接请求会收到明确的版本错误；不再通过编码设置重连、缺失协商编号或缺省高级画质字段兼容旧客户端。浏览器能力不足、硬件编码失败和网络拥塞仍使用正常的能力回退。

## 代码整理

- 将媒体诊断、编码选择、采集恢复和会话恢复职责拆分；统一高级画质参数及类型校验。
- 移除旧客户端编码切换重连分支；当前客户端在会话内重协商编码，保留音频和工具通道。
- 固定 Prettier 版本及格式规则，补齐 CI 格式检查；Dart 使用其自身格式及分析工具。上游提取代码和原始分析证据保留来源校验。
- 对齐网页、服务、Flutter 和锁文件版本；发布检查同时验证 JavaScript 与 Dart 会话协议常量。
- 增加可复用的 Workbench 发布脚本：上传前检查目标、上传后校验哈希、显式激活服务、健康检查失败时回退。

## 验证与发布

- Node：94 项通过；Flutter：94 项通过；Flutter 静态分析通过。
- 浏览器真实 RTP 验证：AV1、VP9、H.264、VP8 及自动模式切换；检查同一 peer、音频、工具通道和接收端反馈。
- 设置界面在 1280、768、390 像素宽度下通过检查。
- Windows 完整发布链通过原生采集、NVENC、Media Foundation、任务调度、托盘和窗口标题栏检查，并完成生产入口构建和安装器打包。
- 网页及信令服务已部署到现有公网入口。公网健康状态为 0.6.0 / 协议 1；HTML、JS、CSS 与构建产物哈希一致。独立临时会话通过认证、信令转发和结束清理验证。

安装器、生产 payload 和部署哈希记录位于本地 `flutter-release/0.6.0/`。测试日志位于 `test-results/`；这些生成物不提交到源码仓库。

本次未在本机自动运行安装器，也未完成新版安装后的 Mac Chrome 公网媒体性能复测。已有旧版客户端上的 AV1 反馈不作为 0.6.0 实测结论。
