# WebDesk 0.6.1（重新发布，构建 14）

本次按指定版本号重新发布 **0.6.1**。Flutter 版本为 **0.6.1+14**，Windows 程序及安装器文件版本为 **0.6.1.14**。包含此前 0.6.2 的生命周期修复，并修复文件选择窗被其他窗口遮住的问题。2026-10-25 的旧 0.6.1 安装包存在首次打开失败的问题，已由本次安装包替换；旧部署记录留在本地 `flutter-release/0.6.1/history/`，不能仅凭安装包文件名区分新旧。

选择器随 Flutter 引擎创建和销毁。系统文件窗在独立 STA 线程运行，结果在平台线程回复一次；关闭和取消都返回空结果，断线按会话归属取消，取消结束前保留并发槽位。COM 接口和线程钩子在工作线程中释放，应用退出不会等待模态线程。主窗口仍按既有托盘规则处理关闭。

本次只在文件选择窗首次激活前，将它放到置顶层级。设置使用 `SWP_NOACTIVATE | SWP_NOOWNERZORDER`，不恢复隐藏或最小化的主窗口，不把主窗口设为置顶。同步窗口调用在状态锁之外执行，避免重入时死锁；激活由系统对话框正常完成，不在激活钩子内递归请求激活，不使用轮询抢焦点或全局窗口钩子。相关行为见 [SetWindowPos](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setwindowpos) 与 [CBTProc](https://learn.microsoft.com/en-us/windows/win32/winmsg/cbtproc)。

新增回归先验证旧实现会被测试置顶窗口遮挡，再验证修复后选择窗确实位于该窗口之前，且主窗口的隐藏、最小化和非置顶状态不变。真实 FlutterWindow / Win32Window / 原生通道门禁覆盖首次打开、关闭、取消、重复打开、旧会话取消隔离及断线取消，检查文件窗打开时 Dart 消息循环仍运行。所有窗口测试仅操作测试进程自身窗口。

审查覆盖网页工具状态、文件传输边界与清理、原生窗口及线程生命周期、Dart 会话和媒体恢复、编码与降级策略、信令认证和路由、发布版本与安装器生产入口。补充了窗口销毁期间字体变更消息的引擎可用性检查。发布元数据现在记录完整构建号和 UTC 构建时间，发布检查约束构建号可用于 Windows 文件版本。

发布结果：Node **94/94**、Flutter **98/98**，Flutter 静态分析、全项目 Prettier、Dart 格式及本次 C++ 格式检查通过。采集、GPU、硬件编码、RTC 分发、标题栏和托盘原生发布门禁通过；浏览器真实 RTP 多编码切换与三种窗口宽度下的工具栏、取消重试检查通过。生产入口为 `lib/main.dart`，payload 共 76 个文件，测试入口及旧选择插件未打入生产包。

公网服务已切换到 `0.6.1 / 协议 1`，发布目录 `/opt/webdesk/releases/0.6.1-oCHsmt`。公网网页资源哈希与本地产物一致，临时会话认证、信令转发及结束清理核验通过。部署中修复 Windows PowerShell 5 将 Workbench 正常上传进度当作异常的问题，保留退出码判断和令牌过滤；额外检查了正常 stderr、非零退出码、过滤及错误策略恢复。

安装包和部署的完整哈希记录在 `flutter-release/0.6.1/deployment.json`。自动化检查不能替代安装后 Mac Chrome 的真实公网会话验收；不同硬件、网络和桌面内容也不存在可统一承诺的最优编码。当前保留多编码协商、实测降级和有界恢复机制。

安装前请从托盘彻底退出旧客户端，再安装本次新生成的安装包。网页服务更新后，在 Mac Chrome 强制刷新并重新连接。
